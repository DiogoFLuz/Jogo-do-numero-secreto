<h1 align="center"> 🔢 Jogo do número secreto!</h1>

Uma aplicação simples e interativa, onde o usuário tenta advinhar um número secreto, gerado aleatóriamente pelo sistema.

## 🚀 como funciona

1. O sistema gera um número aleatório.
2. O jogador incere um palpite.
3. O sistema da um feedback imediato:
   * informa se o palpite foi mais alto.
   * informa se o palpite foi mais baixo.
4. O jogo continua até o usuário acertar o número correto.

## 🛠️ Tecnologias Utilizadas

* **JavaScript** — Lógica principal do jogo.
* **HTML e CSS** — Interface do usuário.
